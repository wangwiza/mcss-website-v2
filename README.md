# MCSS Website v2

[![Netlify Status](https://api.netlify.com/api/v1/badges/af97af33-3006-4fa1-86bd-b57ea1b0212e/deploy-status)](https://app.netlify.com/sites/mcss-website-v2/deploys)

This repository contains the source code for the official website of the McGill Chinese Students' Society (MCSS), the largest and most influential cultural student organization in Eastern Canada. The site is built as a Single Page Application (SPA) using Vue 3 and Vite.


---

## ✨ Features

* **Modern SPA:** A fast and responsive single-page application built with Vue 3.
* **Component-Based Architecture:** Organized into reusable Vue components for pages, UI elements, and data display.
* **Dynamic Routing:** Client-side routing handled by Vue Router for seamless navigation between pages.
* **Interactive 3D Models:** Integration of Three.js to display animated 3D models on various pages.
* **Image Optimization:** Uses Cloudinary for on-the-fly image optimization, lazy loading, and responsive delivery.
* **Data-Driven Content:** Pages like Events, Team, and Sponsors are dynamically generated from JavaScript data files.
* **Comprehensive Pages:**
    * **Home:** A welcoming page with a photo slideshow.
    * **About Us:** Information about MCSS and a "Meet the Team" gallery.
    * **Events:** A historical showcase of past events organized by academic year.
    * **Sponsors & Membership:** A gallery of official sponsors and details on the benefits of the MCSS membership card.
    * **Recruitment:** Displays current open positions and application information.

## 🛠️ Tech Stack

* **Framework:** [Vue 3](https://vuejs.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Routing:** [Vue Router](https://router.vuejs.org/)
* **State Management:** [Pinia](https://pinia.vuejs.org/)
* **3D Graphics:** [Three.js](https://threejs.org/)
* **Image Management:** [Cloudinary](https://cloudinary.com/)
* **Styling:** Vanilla CSS with Custom Properties
* **Linting:** [ESLint](https://eslint.org/)
* **Formatting:** [Prettier](https://prettier.io/)

## 🚀 Project Setup

### Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

### Clone the repository

```sh
git clone [https://github.com/your-username/mcss-website-v2.git](https://github.com/your-username/mcss-website-v2.git)
cd mcss-website-v2
```

### Install dependencies

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with ESLint

```sh
npm run lint
```
